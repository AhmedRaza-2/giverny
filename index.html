    From this page to a skill Claude uses, in under a minute

    1. Copy the prompt

      Each skill has a ready prompt with the exact install command from its author’s repo.

    2. Paste it into Claude Code

      Claude runs the command, checks the skill loaded, and falls back to a manual install if needed.

    3. Ask for the work

      Skills load on their own when your request matches. Each prompt ends with an example to try.

    Prefer the terminal? Open any skill to see the raw command and the Claude Code plugin route.
