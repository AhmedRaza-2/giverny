Claude skills, explained

What are Claude skills?

Claude skills (also called Agent Skills) are folders of instructions, scripts and resources that Claude loads when a task needs them. Each skill has a SKILL.md file with a name and a description; Claude reads the description, and when your request matches, it loads the full instructions. Skills teach Claude specialist work it doesn’t do well by default, like distinctive UI design, video editing with FFmpeg, security audits or SEO.

How do I install a Claude skill?

In Claude Code, the quickest way is a single command such as npx skills add owner/repo --skill name, or a plugin with /plugin install name@marketplace. You can also copy a skill folder into ~/.claude/skills/. On Giverny you just copy the prompt for a skill and paste it into Claude Code; Claude runs the right command for you.

What are the best Claude skills?

It depends on the job. Popular picks: Frontend Design and Impeccable for UI, Superpowers and Matt Pocock’s Skills for engineering workflow, HyperFrames for video, Marketing Skills and Claude SEO for growth, and Office Documents for Word, Excel, PowerPoint and PDF.

Are Claude skills free?

Yes. Every skill listed here is open source on GitHub and free to use under its author’s license. Giverny is free too: sign in with GitHub, follow and star the project, and every copy button unlocks.

Where do Claude skills work?

Skills follow the open Agent Skills format. They work in Claude Code, in the Claude apps (upload a skill in Settings), and through the Claude API. Many also work in other coding agents that read SKILL.md, such as Codex, Cursor and Gemini CLI.

How does Giverny find and update skills?

Giverny reads every SKILL.md in 300+ public GitHub repos each week, files each skill by what it does, and marks skills as New or Updated when their authors change them. Anyone can suggest a repo to add.
